# 🚗 Car Price Prediction Morocco

Machine Learning project to predict used car prices in Morocco using Avito dataset.

## 📊 Features

- Ville
- Marque
- Modèle
- Année-Modèle
- Kilométrage
- Type de carburant

## 🧠 Machine Learning

- Linear Regression
- Scikit-learn
- Pandas

## 🌐 Frontend

- Streamlit

## 📦 Installation

```bash
pip install pandas scikit-learn streamlit joblib
```

## ▶️ Train Model

```bash
python train.py
```

## ▶️ Run App

```bash
streamlit run app.py
```
